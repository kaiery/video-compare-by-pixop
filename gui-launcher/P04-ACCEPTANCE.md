# P04 全部设置界面验收

日期：2026-09-19。状态：**已验收（限设置界面、参数作用范围与预览）**。

所有修改均位于 `gui-launcher/`。没有修改原播放器代码、根 README、原构建或依赖，也没有执行真实比较进程。

## 已交付

- 主窗口新增“全部设置…”入口，提供九个分类：播放与同步、画面与窗口、色彩/HDR、滤镜、解码与硬件、分析窗口、字体、配置与诊断、能力查询。
- 61 项 CLI 均有明确控件：9 项沿用常用界面，52 项进入分类窗口。查询按钮仅生成独立查询参数，未混入比较命令。
- 条目编辑器新增全部 11 个逐视频字段；继承、替换、清空按字段支持，只有滤镜允许追加。
- 公共、左侧、右侧默认分开保存；未指定、指定空值和继承不混淆。复杂滤镜/解码参数由已有核心构造，不在控件中手工拼接命令。
- 草稿确定后写回，取消不改变会话；恢复默认仅影响当前分类。非法数值留在编辑器并显示可定位的诊断。
- 有序 `.opt` 列表支持添加、浏览、移除、上移/下移；自动文件加载明确提示反向映射及外部布尔开关语义。字体支持内置值或文件路径选择。
- 逐视频完整映射随复制、排序保留；列表摘要显示滤镜及其他独立设置数量，编辑器可预览当前条目与公共参数的组合。

完整“源码选项 → GUI 控件 → 参数作用范围 → 验收用例”逐项表见 [P04-CONTROLS.md](P04-CONTROLS.md)，所有 CLI 别名仍由 [COVERAGE.md](COVERAGE.md) 核验。
