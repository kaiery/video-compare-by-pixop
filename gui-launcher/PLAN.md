# 独立 GUI 启动器实施任务计划

创建日期：2026-09-19。这是实施任务清单，不是定时运行任务；没有创建 Windows 任务计划程序条目。当前 P00–P06 已验收，详见任务状态与验收记录。

## 目标与硬边界

1. 不修改原项目任何现有代码、构建文件、测试、文档和 CI；不为 GUI 增加引擎参数、IPC 或内部接口。
2. 全部新增内容在项目根目录的 `gui-launcher/` 内；独立编译、独立进程、独立发布。
3. 一个左侧参考输入加一个或多个启用的右侧输入；右侧按顺序切换，不承诺多视频同时平铺。
4. 完整覆盖当前 61 个 CLI 选项、11 个右侧覆盖字段和现有输入语法。查询命令作为独立工具操作，不混入比较启动。
5. 播放、逐帧、交互裁剪、差异子模式、指标计算等运行操作仍在原比较窗口完成。GUI 提供完整帮助和输出日志，不模拟按键操控播放器。
6. 逐视频独立时间偏移、时间倍率、布局、帧缓冲和播放器远程控制不在本次范围；现有引擎没有相应逐视频参数。
7. 全部 GUI 管理的输出、日志、配置和测试数据位于子目录；用户主动指定外部导出路径时按用户选择执行。默认子进程工作目录为 `gui-launcher/work/`，避免截图等文件写到项目根目录。现有引擎的窗口尺寸保存仅在进程内存中，不生成持久化状态文件。

## 技术方案

- C++17、Win32 Unicode 原生窗口、Common Controls；不要求 MFC、ATL、Python 或额外 GUI 框架。
- 独立 CMake 工程，MSVC x64，Windows GUI 子系统；Windows 宽字符路径从选择文件到进程创建保持完整。
- 数据模型、CLI 参数生成、配置存储、进程管理、日志、界面分层。文件选择使用系统对话框；右侧列表支持多选、拖入、排序、复制、启停和逐条设置。
- 直接创建引擎进程，不经 CMD/PowerShell 转发。规范内部表示为参数数组；Windows 参数转义与 `.opt` 文本语法分开实现。
- 引擎不链接到 GUI。选择已有引擎位置或探测发布目录的 `engine/video-compare.exe`；GUI 自身不要求 FFmpeg/SDL 开发库。
- 用户选择的引擎若不具备源码基线中的能力，明确显示不兼容项，不默默丢弃参数或宣称完整支持。

目录结构（P01 窗口工程、P02 参数核心和测试已建立；后续模块按对应任务创建）：

```text
gui-launcher/

  resources/                         # 图标、manifest、资源文件

  build/ / dist/ / work/              # 子目录内生成产物
```

## 界面与会话

常用页常驻：引擎选择、左侧参考输入、右侧输入列表、布局、窗口策略、差异视图、循环、开始比较、状态。分类页：播放与同步、画面与窗口、色彩/HDR、滤镜、解码与硬件、分析窗口、配置与诊断。

右侧选中条目编辑其覆盖设置；显示“继承 / 覆盖 / 清空（仅支持的字段）”和最终摘要。公共、左侧、右侧公共、单个右侧配置分开存储。滤镜追加使用 `__` 语义，解码器等字段保留底层选项合并语义，不承诺覆盖名称就会清除继承的所有字典项。

会话保存引擎路径、工作目录、输入类型与顺序、启用状态、公共及逐视频设置、显式配置文件、schema 版本。普通文件转成绝对路径；协议地址、图片序列和脚本按输入类型处理，避免误转路径。拖入重复文件允许显式保留，用于自比较。

时间偏移既提供秒数编辑，也提供完整表达式输入（如 `x25.025/24-1:30.5`）；不缩减现有语法。窗口大小支持 `1280x` 和 `x720`。复杂 FFmpeg 参数提供文本编辑、说明和查询入口，不尝试枚举所有第三方滤镜参数。

## 配置优先级与兼容策略

- 引擎的参数装配顺序是：工作目录自动 `.opt` → 显式 `--options-file` 的内容 → 命令行；同名有值选项通常取最后一次。布尔存在型选项不能用“不传参数”撤销文件中的启用状态。
- 默认管理会话传入 `--no-auto-options-file`。允许用户开启兼容加载或指定配置文件；界面必须显示配置来源，不能声称未选中的布尔项必定关闭。
- GUI 能编辑的配置导入应显式解析成模型；无法无损表示的内容保留为兼容文件并显示有效设置/冲突，不默默重写源文件。
- 现有 `.opt` 分词把引号外的 `#` 后所有内容视为结束；双引号内反斜杠参与转义；独立空字符串会丢失。导入/导出按原实现核验，不能假定通用 shell 或逐行注释语法。
- `::` 是逐视频语法的保留分隔符，内嵌该序列的地址/表达式可能不可无损表达；识别并报告原引擎限制，不发出看似有效但含义改变的命令。
- 引擎读取 options 文件使用窄字符文件流，中文 `.opt` 路径在实际 Windows 构建上需验证；如有问题，可在子目录兼容暂存位置复制字节不变的配置并保留原工作目录语义，不修改引擎。
- 长参数列表检测 Windows 进程命令行长度；能无损序列化时使用子目录临时 options 文件，否则阻止启动并给出明确原因，不能截断。

## 进程与日志设计约束

- 起步限制同一 GUI 实例同时运行一个比较会话；能力查询独立管理，可取消并设查询超时，正常比较无固定总时限。
- 创建成功仅代表“进程已启动”，未收到足够证据时不显示“视频加载成功”。记录 PID、起止时间、退出码、argv、工作目录与引擎路径。
- stdout、stderr 都持续异步排空，流来源分别保留；stderr 不自动等同错误。跨流时间顺序只能按收到时间展示，不声称精确原始交错次序。
- GUI 日志采用有限缓存/分批刷新，完整日志采用限额或轮转存储；增量处理跨读取边界的 UTF-8，保留无法解码的原始诊断。
- 用继承句柄白名单和正确关闭管道端，避免进程结束后读线程永久等待。所有退出路径释放线程、句柄和临时配置。
- 关闭启动器时明确提供“保留比较运行 / 结束比较并退出 / 取消”；保留运行必须妥善解除管道捕获或转交后台日志读取，不能留下无人排空的管道。
- 停止比较先请求正常关闭，超时才提供强制终止；只针对本启动器创建的进程，不按进程名批量结束其他会话。

## 验收方法与完成标准

1. 文档覆盖：脚本检查源码选项、全部别名和逐视频键；发现源码新增/删除字段时立即失败。
2. 参数测试：覆盖表每个 CLI/RV ID 验证发出的参数及作用范围，含默认不发出、设置、清空/继承、错误输入；不以界面控件存在作为功能完成。
3. 引擎替身：独立测试 exe 原样记录参数、输出混合日志、模拟挂起/失败，验证中文路径、引号、空字符串和进程清理。
4. 实际引擎：相同媒体及配置分别由 CLI 与 GUI 启动，对照模式、滤镜、切换、窗口、截图和日志。每个结果保存于子目录，记录 PASS / FAIL / BLOCKED / N/A（附原因）。
5. 硬件条件项：10 位显示、多显示器、GPU 加速、特定解码器、VMAF 等不具备条件时标记 BLOCKED 或有依据的 N/A；参数生成通过不能冒充实机功能通过。
6. 全部 61 CLI 和 11 RV 行有实现引用、参数证据、运行结果；所有输入/进程/会话用例执行；没有未解决的高优先级问题。条件项限制在发布说明中列出。
7. 发布前运行 `git diff --name-only` 与 `git status --short`，确认本任务仅新增/修改 `gui-launcher/`；不提交、修改或清理用户原有工作。
