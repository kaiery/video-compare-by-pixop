# P07 手动验收清单

当前不再要求用户执行本清单；按用户授权，P07 本轮已按受限验收收尾。此文仅保留为未来专项回归参考。已有手动证据见 [用户日志确认](P07-USER-VERIFICATION.md)。

本清单仅要求人在原比较窗口操作。自动测试不会发送全局组合键、抢占焦点或移动系统鼠标。不要将“测试未执行”写成 PASS。

## 准备与记录

1. 打开 `dist/video-compare-gui.exe`，在文件菜单打开 `work/p07/resume-safe/RUN-013-keys/session.vcgui`。这是已生成的固定测试会话；核对引擎路径仍是你提供的 EXE。
2. 开始比较后，先用鼠标明确选中标题为 `left.mp4 | right.mp4` 的原比较窗口，再进行该行操作。每组测试结束后退出比较并重新开始，避免裁剪/缩放/交换状态影响下一组。
3. “日志”窗口记录本轮日志目录。使用 F 保存图像到会话工作目录；保留操作前后图片、`stdout.raw`、`stderr.raw` 和 `session.txt`。
4. 对 CLI 对照使用相同引擎、输入和选项、相同工作目录。`session.txt` 是参数证据，不是可直接粘贴进 PowerShell 执行的脚本；使用原项目 Usage 的参数形式启动。启动器不经过 shell。
5. 每行反馈 `ID / PASS、FAIL 或 BLOCKED / 实际观察 / 证据路径`。只做了部分步骤时写“部分完成”并列出未做步骤；用户反馈与自动化证据分别记录。

## 优先关闭三项缺口

| ID | 手动操作 | 必须核对 |
|---|---|---|
| RUN-008 | 鼠标放在画面内部；依次 P、M、X、Shift+X | 像素信息、PSNR/SSIM/VMAF 指标进入日志；FPS 信息可见；出现 `Display state:`。单纯有 Metrics 不足以通过整行 |
| RUN-013 | Ctrl+Shift+W 保存；拖动改变窗口大小；Shift+W 恢复；再改变大小、Ctrl+W 恢复启动尺寸 | 日志出现 Saved/Restored，且实际窗口确实恢复。**仅在原比较窗口手动按组合键**。换进程后不要求记住保存尺寸 |
| RUN-011 | Shift+L 框选，记录裁剪后的尺寸/画面；Backspace 撤销。分别测试 Shift+R、Shift+B；再测试 Ctrl+Shift+L/R 复制裁剪、Ctrl+L/R 清除 | 每一步保存图像和 Shift+X 状态；GUI/CLI 比较前必须确认裁剪尺寸与区域一致。历史失败中左右两条路径分别得到 52×40 和 60×46，不能据此直接认定启动器改变画面 |
